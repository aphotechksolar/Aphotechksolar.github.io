# Aphotech Solar — Quote Upgrade

This upgrade adds `quote.html`, a mobile-friendly custom solar quote form, and links it from the main customer pages.

## Important
- The quote form uses the same Formspree endpoint already used by `contact.html`.
- No Supabase keys or authentication files were changed.
- The quote page is intentionally public so new visitors can request a quote without creating an account.
- After uploading to GitHub Pages, test the form with a real email address and confirm the Formspree submission arrives.
